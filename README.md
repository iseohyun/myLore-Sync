# myLore-Sync

myLore 데스크톱 라이프로그 보관 시스템과 연동되는 스마트폰 동반 안드로이드 애플리케이션입니다.

## 주요 기능
- **QR 코드 기반 간편 자동 페어링**: 복잡한 네트워크 설정 없이 PC 화면의 QR 코드를 스캔하여 1초 만에 자동 연결
- **3대 동기화 조건 실시간 모니터링**: 지정 Wi-Fi 연결, 배터리 충전 중, PC 서버 온라인 상태 감지 시 자동 동기화
- **8대 모바일 라이프로그 수집 및 증분(Delta) 전송**:
  1. 💬 **카카오톡 대화방**: 대화 백업 폴더 감지, 증분 슬라이싱 및 미디어 원본 적재
  2. ✉️ **문자(SMS/MMS)**: 장문/사진 첨부 MMS 포함 증분 동기화
  3. 📞 **통화 기록 & 음성 녹음**: 통화 이력 및 녹음 파일(T전화, 삼성 음성녹음, 워치) 전송 & Gemini STT 마크다운 변환
  4. 🔔 **알림**: 실시간 앱 푸시 및 시스템 알림 캡처
  5. 🎙️ **음성 녹음**: 기기 내 녹음 파일 동기화
  6. 🏃 **삼성 헬스 & 워치 GPS**: 운동 세션 통계 및 GPS 이동 경로(`.gpx`) 동기화
  7. 📇 **스마트 명함 지갑**: 실시간 누적 카메라 보정 + Document Scanner 연동 및 연락처 자동 저장
  8. 📱 **앱 사용량**: `UsageStatsManager` 기반 일자별 스크린타임 리포트
- **좌측 슬라이드 오버레이 드로어 메뉴 & 9대 전용 카테고리 화면 제공**
